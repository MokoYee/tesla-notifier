# 更新日志

## v1.1.1 - 2026-03-28

### 本次新增

- 新增系统健康通知。服务启动后会发送一次自检结果；数据库连续失败或 MQTT 长时间断开时，也会发送提醒和恢复通知。
- 弱网场景下的行程结束通知进一步补强。短时断连、停车离线或服务重启后，漏发的行程通知更容易被补回。

### 体验优化

- 行程结束通知的内容结构更清晰，驾驶评分单独分区展示，阅读更顺眼。
- 行程分析建议文案做了精简处理，避免出现重复表达。
- 行程、充电、日报周报月报、哨兵和安全提醒的通知样式进一步统一。

### 配置更新

- 新增 `SYSTEM_HEALTH_NOTIFY_ENABLED`，用于控制启动自检通知。
- 新增 `FAILURE_ALERT_NOTIFY_ENABLED`，用于控制数据库和 MQTT 故障提醒。
- 新增 `DB_FAILURE_ALERT_THRESHOLD`，用于设置数据库连续失败多少次后告警。
- 新增 `MQTT_DISCONNECT_ALERT_AFTER`，用于设置 MQTT 断开多久后告警。

### 升级说明

- 本次升级没有必须手动迁移的数据结构变更。
- 如果你不想接收系统健康类通知，可以将 `SYSTEM_HEALTH_NOTIFY_ENABLED=OFF` 或 `FAILURE_ALERT_NOTIFY_ENABLED=OFF`。
- 详细环境变量说明请参考 [docs/environment.md](../environment.md)。
