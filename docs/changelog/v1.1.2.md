# 更新日志

## v1.1.2 - 2026-03-29

### 本次修复

- 修复刚插枪后偶发误报“充电意外停止”的问题。
- 修复主动停充、分段充电等场景被误判为异常停止的问题。
- 恢复正常的“充电完成”通知，避免把手动结束也当成异常提醒。

### 体验优化

- 仅在确认进入真实充电流程后，才会判断是否需要发送异常停止提醒。
- 充电异常提醒做了降噪处理，减少短时间内连续弹出多条即时通知。
- 分段补能场景下的通知结果更贴近日常使用习惯，降低打扰感。

### 升级说明

- 已开启充电异常提醒的用户，建议升级到本版本。
- 本次无需新增环境变量，原有配置可继续使用。
- 环境变量说明请参考 [docs/environment.md](../environment.md)。
