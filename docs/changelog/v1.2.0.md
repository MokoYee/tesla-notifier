# 更新日志

## v1.2.0 - 2026-03-31

### 本次新增

- 行程结束通知新增本地特征匹配点评引擎，综合速度、急加速 / 急减速、路况压力和海拔起伏生成更贴近日常驾驶语气的短句点评。
- 行程点评新增 `normal` / `aggressive` 两种文案风格，并支持长时间驾驶、几百公里长途、爬坡、下坡和大起伏山路等专项场景。
- 充电完成通知新增 AC / DC 类型识别与充电效率展示，信息结构更完整。

### 体验优化

- 行程点评文案从固定分支改为静态模板库 + 本地匹配器，后续扩充文案无需继续改核心逻辑。
- `aggressive` 风格文案整体调整为更有活人感的吐槽和夸赞语气，减少说教式表达。
- 充电完成通知中，天气、充电类型、效率、SoC 和表显信息的排版顺序重新整理，阅读更直观。

### 配置更新

- 新增 `DRIVING_COMMENTARY_STYLE`，可选 `normal` / `aggressive`，默认 `normal`。
- 环境变量说明已同步到 [docs/environment.md](../environment.md)。

### 升级说明

- 如果你希望行程结束通知更敢说，可以显式配置 `DRIVING_COMMENTARY_STYLE=aggressive`。
- 本次不需要新增外部依赖，也不涉及数据库结构变更。
- 建议升级后关注一次行程结束通知与充电完成通知的展示效果，确认文案风格符合你的使用习惯。
