# 更新日志

## v1.2.0 - 2026-03-31

### 本次新增

- 行程结束通知新增本地行程画像点评引擎，综合速度、急加速 / 急减速、路况压力和海拔起伏生成更贴近日常驾驶语气的短句点评。
- 行程点评支持长时间驾驶、几百公里长途、爬坡、下坡和大起伏山路等专项场景。
- 充电完成通知新增 AC / DC 类型识别与充电效率展示，信息结构更完整。

### 体验优化

- 行程点评从固定模板改为结构化行程画像，平顺行程给轻量正反馈，风险明显时给直接提醒，激进特征突出时才出现轻吐槽。
- 充电完成通知中，天气、充电类型、效率、SoC 和表显信息的排版顺序重新整理，阅读更直观。

### 升级说明

- 本次不需要新增外部依赖，也不涉及数据库结构变更。
- 建议升级后关注一次行程结束通知与充电完成通知的展示效果，确认文案风格符合你的使用习惯。
