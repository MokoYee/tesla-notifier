# 更新日志

## v1.3.2 - 2026-08-13

### 体验优化

- 行程分析区压缩为“评分、点评、关键因素”三行，移除路况结构、能耗解释、驾驶画像、驾驶动作和行驶场景的重复展示。
- 行程点评改为基于场景基线与样本置信度判断表达强度，短途行程不再因每百公里频次被放大而轻易触发吐槽。
- 行程证据统一收敛到关键因素，最多展示三个有效特征；点评只保留结论和必要建议。

### 算法修复

- 急加速和急减速检测由固定采样点窗口改为真实时间窗口，避免 TeslaMate 采样频率变化导致检测口径漂移。
- 急减速增加最小速度降幅约束，过滤普通收速；短途事件频次按最少 15 km 有效暴露量归一化。
- 海拔分析增加 GPS 瞬时跳变过滤，异常海拔不再被误判为山路起伏，也不会污染点评和关键因素。

### 升级说明

- 本次不涉及数据库结构或环境变量变更。
