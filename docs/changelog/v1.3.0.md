# 更新日志

## v1.3.0 - 2026-06-19

### 本次新增

- 新增 MQTT 新鲜度监控：当 TeslaMate 数据库仍在写入位置数据，但 MQTT 实时状态长时间停滞时，发送系统告警。
- 新增 Grafana 深链：配置 `GRAFANA_BASE_URL` 后，行程和充电通知可点击进入对应详情页。
- 行程结束通知新增上下文洞察，展示路况结构、能耗解释和驾驶画像。

### 体验优化

- 高德调用链统一限流、缓存和负缓存，降低逆地理编码、天气和路况分析共享同一 Key 时触发限流的概率。
- 高德交通态势失败后增加退避和连续失败熔断，避免接口异常时按后台循环频率反复重试。
- 弱网行程补偿先过滤候选行程，已推送行程不再提前加载完整详情，减少无意义数据库查询和地址解析。
- 行程点评从固定模板改为结构化行程画像，平顺行程给克制正反馈，风险明显时给直接提醒，激进特征突出时才轻吐槽。

### 配置更新

- 天气服务移除彩云天气，统一优先使用高德天气，异常时回退 Open-Meteo。
- 新增 `GRAFANA_BASE_URL`，用于生成行程和充电详情页链接。
- 新增 `MQTT_FRESHNESS_MONITOR_ENABLED`、`MQTT_FRESHNESS_CHECK_INTERVAL`、`MQTT_FRESHNESS_STALE_AFTER`、`MQTT_FRESHNESS_DB_ACTIVE_WINDOW`，用于控制 MQTT 新鲜度监控。
- 移除 `DRIVING_COMMENTARY_STYLE`，行程点评不再通过 `normal` / `aggressive` 配置切换风格。

### 升级说明

- 本次不涉及数据库结构变更。
- 如果启用了 `TRAFFIC_ANALYSIS_ENABLED=ON`，建议升级后观察 24 小时内 `traffic` 和 `amap` 告警数量是否明显下降。
- 如果使用 Grafana 深链，需要配置可从手机访问的 `GRAFANA_BASE_URL`。
- 如果旧环境中仍保留 `CAIYUN_TOKEN` 或 `DRIVING_COMMENTARY_STYLE`，可以直接删除。
